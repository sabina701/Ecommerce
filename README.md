# 🛒 E-Commerce Website

A full-stack **E-Commerce Web Application** built with **React, Express.js, MongoDB, and Bootstrap**. The application allows users to browse products, search by category, manage cart and wishlist items, submit reviews, and perform product management operations through authentication.

## 🌐 Live Demo

- **Frontend:** https://sabina701.github.io/Ecommerce
- **Backend API:** https://ecommerce-backend-pdih.onrender.com

---

## ✨ Features

- User authentication (Login / Register)
- Product listing and product details page
- Search products by name
- Product categories
- Add to Cart
- Wishlist management
- Product reviews and ratings
- Add new products
- Edit and delete own products
- My Products page
- User profile page
- Responsive UI with Bootstrap
- REST API integration

---

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/sabina701/Ecommerce.git
cd Ecommerce
```

### Install dependencies

```bash
npm install
```

### Run the frontend

```bash
npm run dev
```

The application will run at **http://localhost:5173**.

---

## ⚙️ Environment Setup

Update the API base URL in `src/api/axios.js`.

### Local Development

```js
baseURL: "http://localhost:5000";
```

### Production

```js
baseURL: "https://ecommerce-backend-pdih.onrender.com";
```
